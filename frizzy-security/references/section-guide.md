# Section guide

Full guidance for the PRD sections this skill owns. Keep the exact headings. Each section opens with the decision; tables for anything comparable; sourced figures carry "checked YYYY-MM-DD"; no placeholders; stable IDs (G-1, F-001, S-01, E-01, R-1, OQ-1, D-01); sentence case headings.

### 13. Security, privacy, and compliance
Follow security-compliance.md. Include the threat model table, OWASP mapping with edition years, authentication and authorization design, the authorization matrix, secret handling, dependency policy, the data map, the legal documents plan with the policy fact sheet in an appendix, cookie and consent design, user-rights flows, regional compliance table, store policy checklist, payment handling, vulnerability response, and an explicit note that policies need legal review.
